# 微光 · Weiguang

一件用 p5.js 制作的互动影像作品：让雾随风舒展，让文字碎成光，再让时间沿来路退回。

表世界是深蓝底色、彩雾、细字与随风落雨；隐藏的里世界沿用相同操作，却用凝视的眼睛、雷电、暗红色和鼠标排斥回应观众。

## 体验

在线地址待首次发布后补充。也可以下载项目，用浏览器打开 `index.html`；所有运行依赖随项目保留，无需安装软件。

建议用桌面浏览器体验鼠标和键盘互动。手机可使用触摸及页面按钮，但尚未完成所有设备与浏览器的兼容验证。

## 操作

| 操作 | 效果 |
| --- | --- |
| 移动鼠标 | 留下彩雾 |
| 左键点按 | 文字柔和淡入，停留约两秒后逐字碎散 |
| 左键按住或拖动 | 表世界搅动彩雾；里世界粒子避开鼠标 |
| R | 表世界开关雨；里世界开关雷电 |
| 按住 T | 沿记录倒流，出现 VHS 质感 |
| 松开 T | 文字定格，天气和彩雾继续前进 |
| S | 保存当前画布 PNG 截图 |
| 两秒内点“重新开始”五次 | 切换表世界／里世界 |

下方输入框可以修改文字，三个滑杆控制原彩雾的停留、变色与扩散。输入框编辑期间不触发快捷键。

文字内容仅在访问者自己的浏览器中保存，不上传到服务器。系统启用减少动态效果时，降低部分运动和闪光效果。

## 制作思路

- **连续噪声风场**：不同位置读取平滑变化的方向，让粒子自然弯曲和分流。
- **文字采样**：从真实笔画像素提取碎片，逐字淡出并沿风飘散。
- **轨迹回放**：记录状态后倒序恢复，实现原路返回；文字有独立历史，松键可定格。
- **对应的两个世界**：复用操作，通过相反的反馈改变观众感受。

创作方向、视觉取舍、互动需求与体验反馈由项目创作者提出，Codex 协助技术实现、排查及逻辑验证。

创作者：[purpleblu](https://github.com/purpleblu)。

## 文件

- `sketch.js`：彩雾、旋涡、风向与场景绘制。
- `memory.js`：排版、淡入、笔画采样、碎散和文字倒流。
- `weather.js`：雨滴与落地涟漪。
- `timeline.js`：场景状态记录与倒流控制。
- `effects.js`：VHS、时间戳、快捷键与截图。
- `hidden-world.js`：隐藏入口、眼睛、雷电与里世界反馈。

有 Node.js 时，可运行 `node tests/smoke.cjs` 检查交互逻辑。测试不替代实际浏览器视觉验收。
